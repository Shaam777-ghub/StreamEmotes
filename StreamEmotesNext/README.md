# StreamEmotes Next — iPhone, v0.1

Новый независимый клиент Twitch с интерфейсом на русском языке. Это исходники первой версии, **не подписанный IPA и не проверенная на физическом iPhone релизная сборка**. Старый проект StreamEmotes не изменялся.

## Реализовано в коде

- Тёмная лента русскоязычных трансляций, поиск каналов и прямые эфиры отслеживаемых каналов.
- Экран трансляции с отдельным чатом, портретная и горизонтальная компоновка.
- Вход через Twitch Device Code для публичного OAuth-приложения, обновление и проверка токена; хранение в iOS Keychain.
- Чтение Twitch IRC через TLS WebSocket, переподключение, удаления сообщений и очистка чата. Отправка через официальный Send Chat Message API с обработкой отказа Twitch.
- Twitch emotes по диапазонам IRC, глобальные и канальные 7TV/BetterTTV, анимация средствами WebKit, наложение zero-width эмотов.
- Список смайликов с поиском и вставкой в сообщение.
- Глобальные и канальные Twitch badges, BetterTTV badges, выбранный 7TV badge.
- Активный 7TV paint: цвет, линейные/радиальные градиенты, изображения, тени; данные через актуальный v4 GraphQL.
- Переключатели расширений, оформления ников, значков и размер текста.
- Ограничение истории чата до 400 сообщений, кеш косметики, ограниченная параллельность запросов, текстовые сообщения об ошибках.

«Изменение никнеймов» здесь означает **отображение оформления выбранного ника**, а не изменение Twitch username. Переименование других пользователей или управление подпиской 7TV не реализовано. BetterTTV предоставляет смайлики/значки; универсальные 7TV paints не выдаются за функцию BTTV.

## Архитектура

SwiftUI-приложение iOS 17+ с локальным WebKit-интерфейсом. Это гибридная реализация, не полностью нативный SwiftUI-клиент. Веб-интерфейс включён в bundle и не загружает удалённый JavaScript, кроме официального Twitch Player на отдельной HTTPS-странице.

- `App/StreamEmotesApp.swift`: оболочка, Keychain, сетевой мост с allowlist хостов; только локальный главный frame имеет доступ к мосту. Междоменные HTTP redirects запрещены.
- `App/Web/core.js`: разбор IRC, позиционирование смайликов и отображение paints.
- `App/Web/app.js`: API, авторизация, каналы и чат.
- `Hosting/player.html`: отдельная страница официального Twitch Player.
- `project.yml`: проект XcodeGen.
- `.github/workflows/ios.yml`: сборка без подписи для iOS Simulator. При размещении в существующем репозитории используется корневой `.github/workflows/streamemotes-next.yml`; он проверяет тесты и сборки новой версии.

## Что нужно для реального запуска

1. Зарегистрировать публичное приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps). В приложении открыть «Настройки → Подключение приложения» и указать его Client ID. **Client Secret вводить или отправлять не нужно.**
2. Разместить `Hosting/player.html` на HTTPS-хостинге и указать полный URL этой страницы в настройках. Twitch embed требует действительный parent-домен. До этого приложение явно показывает, что встроенный плеер не подключён, и предлагает открыть Twitch отдельно.
3. На Mac установить Xcode и XcodeGen, затем выполнить из корня архива:

```sh
xcodegen generate
open StreamEmotesNext.xcodeproj
```

В Xcode выбрать iPhone Simulator и Run. Для физического iPhone указать свою Signing Team и уникальный Bundle Identifier. Настройка Apple signing/TestFlight не выполнена; архив для Simulator нельзя установить на iPhone как IPA.

Проект загружен в `Shaam777-ghub/StreamEmotes`, ветка `streamemotes-next`, папка `StreamEmotesNext`. Корневой workflow `StreamEmotes Next checks` автоматически проверяет изменения этой папки. Для отдельного репозитория можно использовать вложенный `.github/workflows/ios.yml`. Сборка создаёт `.app` для симулятора, не подписанный IPA.

## Проверка

```sh
node --test Tests/core.test.cjs
node --check App/Web/app.js
node --check App/Web/core.js
# Дополнительная проверка интерфейса: Node + Playwright + Chromium
npm install --no-save playwright
npx playwright install chromium
node Tests/ui.test.cjs
```

Модульные тесты проверяют IRC-теги, Unicode-позиции эмотов, конфликтующие диапазоны, недоверенные URL изображений и текущую модель градиентов. UI-тест использует синтетические ответы API и WebSocket: он не входит в реальный аккаунт и не отправляет сообщения людям.

## Ограничения первой версии

- GitHub Actions успешно выполнил компиляцию для iOS Simulator и iPhone без подписи, а также UI-тест с синтетическими ответами API. Реальный запуск на устройстве/симуляторе, сетевой мост Swift, Keychain и встраивание видео ещё требуют проверки на iOS.
- Нет заданных Client ID и HTTPS-хостинга: полный вход, получение персональных каналов, реальная отправка и воспроизведение не проверены.
- Интерфейс использует знакомую структуру Twitch, но не является точной копией всех его экранов. Нет клипов/VOD, подписок и покупок, Drops, модераторских инструментов, мини-плеера между вкладками, push-уведомлений, глубокой VoiceOver-проверки.
- Настройки сохраняются локально. OAuth-токен находится в Keychain. Для отзыва доступа на стороне Twitch используйте настройки подключений Twitch; кнопка выхода удаляет локальную сессию.
- 7TV/BTTV эмоты обновляются при открытии канала; live-события изменения наборов и личные наборы 7TV пока не поддерживаются. Косметика обновляется по сообщениям с кешем 10 минут. При большом количестве новых авторов часть оформления может появиться позднее.
- Изображения paints поддерживаются, но сложные режимы смешивания/прозрачности отдельных изображений не гарантируют идентичный вид расширению.
- Палитра содержит 7TV/BTTV; Twitch emotes отображаются во входящих сообщениях, но отдельная палитра подписочных Twitch emotes пока не реализована.
- Свои сообщения, подтверждённые Send Chat Message API, могут отображаться без Twitch badges/emote ranges до прихода IRC-эха.
- Список ограничен первыми 40 результатами; бесконечная прокрутка не реализована. API могут менять форматы и лимиты.
- Производительность при очень быстром чате и работа в фоне ещё требуют проверки на устройстве.

## Плеер и вход (доработка 2 ноября 2026)

Плеер открывает HTTPS-страницу GitHub Pages в отдельном WKWebView. У удалённой страницы нет native bridge и доступа к токенам приложения. При выходе из канала плеер уничтожается; настройки временно скрывают его. В портретной ориентации выделено 300 pt по высоте.

Без авторизации можно ввести точный ник канала в поиске и читать публичный чат. ROOMSTATE сообщает ID канала для загрузки 7TV/BTTV. Отправка сообщений и значки Twitch через Helix требуют входа. Наличие сообщений в чате само по себе не подтверждает, что канал сейчас в эфире.

Кнопка «Войти с логином и паролем» открывает официальный Twitch в SFSafariViewController. Пользователь вводит пароль и 2FA только на стороне Twitch. Приложение использует Device Code Flow; Twitch может попросить ввести показанный код и подтвердить доступ. После подтверждения окно закрывается, токены сохраняются в Keychain. Пароли приложение не получает и не хранит.

Нужно один раз указать Client ID зарегистрированного приложения Twitch с типом **Public** в настройках подключения. Client Secret не требуется и не должен встраиваться в клиент. До выпуска Client ID следует задавать разработчику, чтобы конечные пользователи не настраивали его вручную.

Проверки `Tests/session.test.cjs` используют подставные ответы OAuth: успешный вход, отмена, обновление с ротацией, параллельные запросы, повтор после 401, временная ошибка и отозванная сессия. Они не заменяют реальную авторизацию пользователя. `testGuestStreamAndChat` в XCTest подключается к настоящему публичному чату и сохраняет фактический экран плеера, включая ошибку плеера, если она возникнет. Сообщений людям тест не отправляет.
