# Проверка версии 0.1 — 2 ноября 2026

Подтверждено:

- `node --check` для app.js, core.js и ui.test.cjs — успешно.
- `node --test Tests/core.test.cjs` — 6/6 тестов успешно.
- Реальные HTTP-запросы: глобальные и канальные 7TV emotes, глобальные и канальные BetterTTV emotes, BetterTTV badges — успешные JSON-ответы.
- Реальный запрос к `https://7tv.io/v4/gql` с GraphQL-запросом из приложения — выбранные paint и badge получены. Реальные данные paint прошли преобразование в CSS.

Не подтверждено:

- UI smoke test: не запускался до выполнения сценария — отсутствует Chromium; автоматическая загрузка браузера завершилась ошибкой повреждённого архива. Тест сохранён для запуска в подходящей среде.
- Xcode build / iOS Simulator / физический iPhone: недоступны в этой Linux-среде.
- Реальная OAuth-сессия Twitch, обновление токена, загрузка отслеживаемых каналов, чтение/отправка сообщений, Keychain: нужен Client ID и вход пользователя.
- Twitch Player: нужен HTTPS-хостинг и проверка поведения embed в iOS WebKit.
- GitHub Actions: workflow подготовлен, запусков из этого проекта не было.

Таким образом, архив — первый исходный проект, а не готовый релиз или гарантия успешной сборки.
